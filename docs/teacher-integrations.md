# 班主任工作台：真实服务接入

当前班主任工作台和独立原生小程序使用本机持久化存储。设置提醒代表记录提醒计划，不能据此声称已向微信发送消息。学生情况、访谈和事件内容不应放入外部通知正文。

## 本机图片识别

`npm run dev` 中的 `teacherOCR()` 插件提供 `/api/teacher/ocr`。macOS 使用 Apple Vision 在本机识别简体中文和英文；图片临时文件在识别后删除，不写入日志，也不发送外部 OCR 服务。单张图片最大 10 MB。第一次调用需要本机可用的 Xcode Command Line Tools / Swift；没有运行环境时接口返回未配置。

此插件只在 Vite 开发服务中运行。静态部署或原生小程序不会自动获得本机 OCR 服务；网页会明确提示未配置，仍可粘贴文字、核对导入草稿。在学校周程表中，OCR 只提供文字结果，日期、时间和表格关系必须由老师检查后保存。

## 微信小程序订阅消息

接入需要真实小程序 AppID、服务类目、与实际业务匹配的订阅消息模板和可用 HTTPS 后台。老师点击订阅按钮后调用 `wx.requestSubscribeMessage`；服务端保存授权结果和必要的接收标识，并按实际授权范围创建发送任务。一次性订阅和长期订阅能力分别核实，不把勾选提醒视为平台授权。

后台定时任务统一读取未完成事项、关爱跟进、事件复查和本周班会主题记录。发送前重新检查事项状态、日期、授权和免打扰设置，以任务版本及提醒时间组成幂等键，取消或改期时使旧任务失效。消息接口返回成功时只记为发送成功；不据此推断用户阅读情况。失败保留原因和重试次数，并在提醒中心提示。

## 微信服务号

服务号与小程序订阅消息是两条接入渠道。开通服务号账号能力、确认适用模板及用户关系后，再实现公众号身份绑定和后台发送。AppSecret 等凭证只保存到后台密钥环境；不要写入前端、小程序包、仓库或备份。

当前代码未部署微信发送服务、未建立后台定时任务，无法在用户关闭应用后真实推送。接入完成前，界面须继续显示“未连接微信提醒”，不能显示“微信提醒已开启”。

## 云端学生资料

班主任数据独立于现有个人日程数据。正式共享或同步前，应建立账号隔离、查看权限、传输与存储保护、导出脱敏及删除流程。未来接入模型或云 OCR 时，应在上传前向老师说明需要处理的内容与服务方，并只发送完成该次处理必需的数据。
