# 知班 · 班主任工作平台

这是在原有“时序”项目中新增的班主任工作平台。原日程系统保留于 `/planner`，原生微信项目 `mini-src` 不受影响。知班使用独立存储，原个人计划不会被迁移或覆盖。

## 网页端

运行 `npm run dev`，访问终端显示的本机地址（默认 http://127.0.0.1:5173/）。首次进入展示标注为虚构的示例资料，可点击“清空示例，开始使用”。网页支持手机布局。

- 工作台：今日待办、往期未完成事项、近期学生跟进、待办结事件与每日关怀。
- 每日待办：新增、编辑、完成、取消、改期，按时间或优先级排序。提醒与完成分别控制。
- 周程／学期：同一事项自动显示于周历、月历和对应当天的待办；支持跨天安排、逐项编号与提醒开关。
- 文本导入：逐行整理中文日期、星期、时间、类别和优先级。预览可修改日期、时间和标题；模糊日期必须补充，重复事项跳过。
- 图片导入：Mac 本机开发服务使用 Apple Vision 识别中文图片，再走相同的人工确认流程。服务未启动、平台不支持或识别失败时显示原因，可粘贴文字继续。
- 班会：记录主题、日期时间、计划／已开展、内容与后续措施；班会同步为日程事项。
- 学生：使用代号记录情况、日期和时间明确的访谈、采取措施、下次跟进；自动形成跟进日程。
- 事件：时间、经过、方法、结果、状态、学生关联、复查时间和文件夹；支持拖拽及下拉移动、HTML档案导出、浏览器打印／存为PDF。
- 总结：周、月、学期、自然年统计，生成可编辑的文字草稿并导出；完成事项计入完成时间，事件办结使用结案时间，班会按实际已开展记录统计。
- 提醒：站内可查看事项、关爱、复查、班会主题检查计划；免打扰时间顺延；关联事项只生成一份提醒。
- 数据：当前浏览器自动保存，严格校验JSON备份恢复，支持上一步撤销。数据异常时阻止覆盖，并提供原始资料导出。

## 原生微信小程序

运行：

```sh
npm run build:teacher-mini
npm run typecheck:teacher-mini
```

微信开发者工具导入 `teacher-miniprogram/`。开发源文件为 `teacher-mini-src/`。默认使用游客AppID供工具查看；手机预览、体验版和正式发布需要自己的微信小程序AppID。

复制 `teacher-mini.config.example.json` 为 `teacher-mini.config.local.json` 填写公开配置后重新构建；AppSecret等秘密只能放服务器。原生端也是独立本机存储，支持JSON备份互导，尚未提供账号和云同步。

## 需要真实账号与部署的能力

微信服务号推送、小程序订阅消息、定时后台发送、真机图片OCR和教师账号／跨设备同步需要接入服务端及微信配置。界面会明确显示未接入，不会将提醒开关视为成功发送消息。部署检查与接口约定见 `teacher-integrations.md` 和 [小程序说明](../teacher-mini-src/README.md)。

当前每日关怀内容为60条审核句库：同日保持同一句，一轮内按展示历史去重，用尽后会循环。要满足长期持续不重复，需要持续更新审核内容库。
