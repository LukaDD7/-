# 知班 · 原生微信小程序本地体验版

这是独立于原有时序小程序的原生客户端，共用 `lib/teacher.ts` 的数据格式、文字识别、日期规则和统计逻辑。现有 `mini-src/`、`miniprogram/` 和旧时序资料不会被修改。

## 构建和打开

在项目目录运行：

```sh
npm run build:teacher-mini
npm run typecheck:teacher-mini
```

将生成的 `teacher-miniprogram/` 导入微信开发者工具。没有配置 AppID 时使用 `touristappid`，仅用于允许游客项目的开发者工具体验。真机预览和上传需要自己的小程序 AppID、微信开发者权限及平台审核。

公开配置可从 `teacher-mini.config.example.json` 复制为 `teacher-mini.config.local.json` 后填写，再重新构建。AppSecret、OCR 服务商密钥等必须留在服务端，不能加入配置文件或小程序代码。

## 已实现

- 工作台：今日、逾期、全部、已完成清单；时间与优先级排序；工作完成状态、提醒偏好独立操作；本周统计；每日关怀语；待跟进学生和未办结事件。
- 日程：可切换日期的周程和月历、校历周次、一天多项自动编号、分类筛选、提醒圆圈。与待办使用同一份记录。
- 通知/周程文字识别：基准日期、逐项编辑确认、缺失日期提示、分类与提醒设置、去重导入。采用确定性关键词/日期规则，不虚称大模型理解。图片识别服务未配置时明确提示，不伪造识别结果。
- 学生关爱：学生代号、情况描述、带日期和时间的访谈时间轴、措施、下次跟进、关联事件；跟进日期生成工作事项。
- 班会：日期、时间、主题、实际内容、开展状态、后续安排；保存后同步生成/更新日程工作。每周补录偏好在工作台到时显示，已记录本周主题则不再提示。
- 事件：时间、事件、方法、结果、处理状态、学生关联、复查日期、办结时间、档案表导出。长按卡片选择移动文件夹。
- 总结：周/月/年/学期统计、可查看来源明细、总结文本导出。工作按实际完成时间统计，班会按实际开展日期统计，事件新增与办结分开统计。
- 完整 JSON 备份导出、格式校验后导入恢复；与网页共享格式。异常本地资料不会被静默覆盖，可导出原始备份后恢复。

## 数据保存和当前边界

这是**本机资料模式**，通过 `wx.setStorageSync` 保存，存储键为 `qinghe.teacher.mini.v1`。没有连接云端、登录和多设备自动同步；小程序本机数据与网页本机数据相互独立，可以通过 JSON 备份迁移。更换设备、清理微信缓存或删除小程序可能丢失数据，请定期备份。

所有学生示例使用虚构代号，内容注明示例。没有实现自动诊断、自动贴标签或未经用户操作向外发送学生资料。

当前为单一班级工作台，班级名称和学期是这份资料的元数据；更换名称不切换另一套资料。新学期可先导出旧资料再清空开始新资料。

删除和清空通过原生确认弹窗执行；当前没有回收站。导出的 HTML 档案可在电脑浏览器打开打印，或打印另存为 PDF，不宣称生成了原生 Word 文件。生成示例、测试通过、TypeScript 构建成功不代表微信开发者工具已编译或真机已验证。

## 微信提醒

各模块的提醒开关和提前分钟数会保存到本机，应用内显示待跟进信息。**当前没有配置后台定时发送，也不会主动推送微信消息。**

在“我的”可填写公开的订阅消息模板 ID，并在用户主动点击按钮时调用 `wx.requestSubscribeMessage` 测试本次订阅授权。授权结果不代表消息已发送，也不保证未来订阅次数充足。

上线需要按实际账号资质和类目选用审核通过的模板，服务端保存用户标识和有效授权，在 Asia/Shanghai 时区执行定时任务，检查完成/取消/改期状态，遵守免打扰设置，记录发送失败与重试，避免重复发送。

服务号消息属于独立渠道，本客户端未配置公众号关联、服务号模板或发送后台，不会把小程序“服务通知”伪装为公众号消息。服务端接入时应仅在外部提醒中放普通工作摘要，不发送学生访谈或事件敏感详情。

## 图片 OCR 可选接口

`ocrUrl` 配置 HTTPS 接口并在微信公众平台登记合法上传域名后，用户选择图片并同意上传，客户端使用 `wx.uploadFile` 上传字段 `image`。接口应返回 JSON `{"text":"识别出的原始文字"}`，识别文字先进入可编辑文本框，老师核对后再生成工作草稿。

接口应在服务端实现身份校验、限流、大小限制和短期文件清理；当前客户端没有云端登录令牌，仅供开发环境对接验证，不建议直接配置无需鉴权的公开 OCR 接口。

OCR URL 未配置时，图片不会被上传，文字识别和手工录入继续可用。
